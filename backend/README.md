
# AgriGrade AI Backend

## Requirements
- Python
- pip
- Git (optional)

## Setup
Create a virtual environment and install dependencies.

## Configuration
Create a local .env file and configure the model paths
and external API credentials.

## Run
uvicorn main:app --reload

## API Documentation
http://127.0.0.1:8000/docs

## Main Endpoint
POST /api/predict
